# 🚀 VortexSpeed // Quantum Telemetry Engine

VortexSpeed is a modern, high-performance network telemetry dashboard designed to give users real-time insights into their network performance. Combining high-fidelity simulated test profiles with real-world WebSocket/XHR live network probing, VortexSpeed provides accurate metrics wrapped in an ultra-sleek, cyberpunk-inspired visual interface.

## ⚡ Core Features

* **Dual Engine Modes:** * *Real Network Probe:* Hits real network nodes (via Cloudflare/Google endpoints) to precisely map real-time ping stability, download speeds, and upload capabilities.
    * *Simulated Mode:* High-fidelity preset plans ranging from standard VDSL to a blazing-fast 10Gbps Multi-Gig Fiber network to show what your hardware or connection is capable of.
* **Web Audio SFX Engine:** Includes an audio-reactive synthesizer that shifts oscillator frequencies and filter cutoffs in real-time based on your current network speeds, complete with immersive chime indicators.
* **Live Telemetry Graphing:** Integrates a fast Canvas-based charting engine (`Chart.js`) mapping real-time upload and download throughput fluctuations smoothly.
* **Dynamic Theme Engine:** Switch instantly between 4 beautiful, custom-tailored design systems via CSS Custom Tokens: **Carbon Dark**, **Neon Cyberpunk**, **Aero Glass**, and **Zenith Light**.
* **Geographical Node Discovery:** Multi-API fallback engine to safely resolve your current public IPv4 address, ISP data, Autonomous System Number (ASN), and geographical routing node.
* **Automated Certification:** Generates an on-the-fly, high-resolution graphic on a `<canvas>` containing all of your validated telemetry metrics, ready to be downloaded as a image or copied to clipboard.
* **Telemetry Logs & Analytics:** Local storage history logging with built-in export capabilities to standalone `.csv` data sheets.

## 🛠️ Architecture & Technologies Used

VortexSpeed is built entirely using a single-file clean architecture, ensuring zero bulky framework overhead and maximum client-side execution speeds:

* **Semantic HTML5 & Dynamic SVG Mapping** for the vector-based speedometer needle and animated packet particle transmission map.
* **CSS Custom Properties & Glassmorphism** utilizing structural backdrops (`backdrop-filter: blur()`) and fluid cubic-bezier animations.
* **Vanilla JS (ES6+) Component Design** managing encapsulated states safely without leaking memory or blocking UI threads.
* **Chart.js** via CDN for clean data visualization mapping.
